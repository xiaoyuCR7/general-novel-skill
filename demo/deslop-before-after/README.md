# 去 AI 味前后对照

同一场戏的两个版本，用来复现去 AI 味流程的机器结果。`before.md` 是故意写入常见套路腔的样稿，
`after.md` 是按 `references/craft/anti-ai-style.md` 与 `references/craft/deslop-engineering.md`
修订后的版本。事实、人物、对白内容和事件顺序没有变化，也没有新增情节。

## 复现

```bash
python scripts/check_text.py "demo/deslop-before-after/before.md" --gate-report
python scripts/check_text.py "demo/deslop-before-after/after.md" --gate-report
```

## 机器结果

| | before | after |
|---|---|---|
| blocking 命中 | 9 | 0 |
| advisory 命中 | 3 | 0 |
| AI 味分数 | 76.2（重度） | 0.0（轻度） |
| 非空白字符数 | 328 | 256 |

删改比例：删除 92 字、新增 20 字，合计 112 / 328 = 34.1%，在重度上限 35% 以内。

## 逐处处理

| 原文 | 命中 | 处理 | 理由 |
|---|---|---|---|
| 声音不大，却带着不容置疑的分量 | 音量反差腔、禁用词 | 留“声音不大” | 后半句是空泛定性，下一句“这话没有问的意思”已交付同一信息 |
| 深吸一口气，心中涌起一股难以言喻的不安 | 身体套词、心理告知 | 删 | “每一句都像在替自己开脱”已呈现不安，属重复告知 |
| 都仿佛是在替自己开脱 | 禁用词 | 改“像是” | 这里是人物的真实感受，不是回避描写，保留比法只换词 |
| 他很紧张，指节发白地攥紧了铜扣 | 心理告知、身体套词 | 改“把铜扣攥得更紧了些” | 保留攥铜扣这个承载线索的动作，删重复的情绪命名 |
| 他不禁想起 | 禁用词 | 改“他想起” | 套词无功能 |
| 沉声道 | 公式化标签 | 改“说” | 一个字的回答不需要语气修饰 |
| 嘴角勾起一丝冷笑 | 禁用词 | 改“冷笑了一声” | 冷笑是师兄的态度信号，保留反应，只去套词 |
| 这一刻，陈墨终于明白，这不是…而是…清算 | 起手式、否定对比 | 改“陈墨这才知道，今晚的盘点，查的是他” | 保留“盘点是冲他来的”这一认知变化，去掉拔高句式 |
| 而这一切，才刚刚开始 | 预告式收尾 | 删 | 不承载信息，让上一句的认知变化收尾 |

## 这份对照说明什么、不说明什么

- 说明：检测规则能定位这些模式；按“删除优先、最小修复、保留功能”修订后门禁清零，
  且删改量受上限约束。
- 不说明：成稿的文学质量。样稿与修订稿都由模型按规则写成，机器清零不等于写得好，
  也不代表能通过任何 AI 检测器。
